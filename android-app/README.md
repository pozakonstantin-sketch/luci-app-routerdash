# RouterDash для Android

Нативная Android-оболочка для RouterDash 1.4.0. Она открывает веб-дашборд на самом роутере в защищённом WebView, поэтому сохраняются все восемь разделов RouterDash и существующая интеграция с LuCI/ubus.

## Возможности первой версии

- подключение по адресу роутера (например, `http://192.168.1.1`);
- вход через штатную форму LuCI — отдельный пароль в приложении не хранится;
- сохранение только адреса роутера;
- JavaScript и DOM Storage для работы интерфейса RouterDash;
- блокировка переходов на сторонние сайты из WebView;
- запрет смешанного HTTP/HTTPS-контента и сторонних cookie;
- кнопка смены адреса и перезагрузки страницы.

## Требования

- Android 8.0 (API 26) или новее;
- OpenWrt с LuCI и установленным пакетом RouterDash 1.4.0;
- телефон должен иметь сетевой доступ к роутеру (Wi-Fi, VPN/Tailscale или другой маршрут).

## Сборка

Откройте каталог `android-app` в Android Studio (JDK 17, Android SDK Platform 36), дождитесь синхронизации Gradle и выполните **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Безопасность

OpenWrt часто использует HTTP в локальной сети. Приложение разрешает cleartext HTTP, чтобы поддержать такие установки; при подключении через недоверенную сеть используйте HTTPS через доверенный сертификат или защищённый VPN. Не отключайте проверку TLS-сертификатов. Пароль LuCI не сохраняется приложением.
