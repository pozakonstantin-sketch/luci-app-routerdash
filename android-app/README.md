# RouterDash для Android

Полноценный нативный клиент RouterDash для OpenWrt. Интерфейс построен на Kotlin и Jetpack Compose (Material 3); данные запрашиваются напрямую через LuCI JSON-RPC/ubus. Веб-дашборд и WebView приложению не нужны.

## Что уже реализовано

- Нативный экран подключения к роутеру и вход через LuCI.
- Пароль используется только при авторизации и не сохраняется.
- Сохранение адреса роутера.
- Отдельные Compose-разделы: обзор системы, сетевые интерфейсы, DHCP-клиенты, службы и системный журнал.
- Данные запрашиваются напрямую у LuCI/ubus.
- Обработка ошибок подключения и сессии.
- Android 17: compileSdk/targetSdk 37 и запрос разрешения ACCESS_LOCAL_NETWORK.
- Material 3, тёмная тема, нижняя навигация и адаптивная ширина контента.

## Требования

- Android 8.0 (API 26) или новее.
- Android SDK Platform 37 и JDK 17 для сборки.
- OpenWrt с LuCI и доступным JSON-RPC.
- Сетевой маршрут от телефона до роутера: Wi-Fi, VPN/Tailscale или другой туннель.

## Сборка

Открой каталог `android-app` в Android Studio с установленным Android SDK 37. Либо из каталога проекта выполни:

```sh
gradle --no-daemon assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions workflow **Android app** автоматически собирает debug APK и публикует его как artifact.

## Безопасность

Пароль LuCI не записывается в SharedPreferences и очищается из поля после входа. В памяти приложения остаётся только токен текущей сессии. Для локальных установок OpenWrt с HTTP включён cleartext-трафик; для доступа через недоверенные сети используй HTTPS с доверенным сертификатом либо VPN. Не отключай проверку TLS-сертификатов.
