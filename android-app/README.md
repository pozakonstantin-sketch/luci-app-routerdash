# RouterDash для Android

Полноценный нативный клиент RouterDash для OpenWrt. Интерфейс построен на Kotlin и Jetpack Compose (Material 3); данные запрашиваются напрямую через LuCI JSON-RPC/ubus. Веб-дашборд и WebView приложению не нужны.

## Что уже реализовано

- Нативный экран подключения к роутеру и вход через LuCI.
- Адрес, имя пользователя и пароль LuCI сохраняются в EncryptedSharedPreferences с ключом Android Keystore для повторного входа; SSH-реквизиты для фоновой автозагрузки сохраняются отдельно только после явного включения функции.
- Сохранение адреса роутера.
- Отдельные Compose-разделы: обзор системы, сеть, DHCP-клиенты, диски, пакеты, загрузки, службы, VPN, firewall, SSH-терминал, синхронизация файлов и системный журнал.
- Двусторонняя синхронизация телефона с SSD роутера по SFTP: сравнение файлов, выбор направления, обработка конфликтов, создание каталогов и безопасная передача без зеркального удаления.
- Ручная синхронизация использует открытую SSH-сессию; для фоновой автозагрузки SSH-реквизиты сохраняются только по явному согласию пользователя в зашифрованном хранилище Android Keystore.
- Проверка точки монтирования внешнего накопителя перед созданием каталога синхронизации, чтобы не записывать данные на overlay при отключённом SSD.
- Данные запрашиваются напрямую у LuCI/ubus.
- Обработка ошибок подключения и сессии.
- Android 8.0+ (minSdk 26), compileSdk/targetSdk 36. На Android 17 приложение пока остаётся на targetSdk 36: это сохраняет совместимость без преждевременного запроса ACCESS_LOCAL_NETWORK; перед переходом на API 37 потребуется отдельная проверка сетевых разрешений.
- Material 3, тёмная тема, нижняя навигация и адаптивная ширина контента.

## Синхронизация с SSD

1. Подключись к роутеру в RouterDash.
2. Открой раздел «SSH-терминал» и установи SSH-соединение.
3. Перейди в «Синхронизация», выбери папку телефона и укажи каталог SSD (по умолчанию `/mnt/sda/RouterDashSync`).
4. Нажми «Сравнить файлы», проверь направления передачи и вручную разреши конфликты.
5. Запусти синхронизацию. Удаление файлов с любой стороны не выполняется.

На роутере должен быть включён SFTP subsystem для SSH-учётной записи. Если сервер отвечает `subsystem request failed` или `SFTP server not available`, настрой SFTP-сервер на OpenWrt. Для первого запуска проверь, что SSD смонтирован и доступен для записи. Большие передачи лучше выполнять при стабильном Wi-Fi или Tailscale-соединении.

## Требования

- Android 8.0 (API 26) или новее.
- Android SDK Platform 36 и JDK 17 для сборки.
- OpenWrt с LuCI и доступным JSON-RPC.
- Сетевой маршрут от телефона до роутера: Wi-Fi, VPN/Tailscale или другой туннель.

## Сборка

Открой каталог `android-app` в Android Studio с установленным Android SDK Platform 36 и JDK 17. Либо из каталога проекта выполни:

```sh
gradle --no-daemon assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions workflow **Android app** автоматически собирает debug APK и публикует его как artifact. Подписанные release APK и AAB собираются отдельным workflow **Android release** после настройки GitHub Secrets; инструкция — `docs/store/release-signing.md`.

## Безопасность

Пароль LuCI сохраняется в зашифрованном хранилище Android (EncryptedSharedPreferences с ключом Android Keystore), чтобы поддерживать повторный вход. В обычных SharedPreferences пароль не записывается. SSH-пароль для фоновой автозагрузки сохраняется в зашифрованном хранилище только после явного включения этой функции. Для локальных установок OpenWrt с HTTP включён cleartext-трафик; для доступа через недоверенные сети используй HTTPS с доверенным сертификатом либо VPN. Не отключай проверку TLS-сертификатов.

Политика конфиденциальности: [docs/privacy-policy.md](../docs/privacy-policy.md). Перед публикацией необходимо заполнить контактные данные владельца приложения и разместить политику на общедоступном HTTPS-адресе.
