## 2. Как работает приложение

RouterDash — клиент для управления маршрутизаторами на базе OpenWrt. Приложение подключается непосредственно к адресу роутера, который указывает пользователь. Для получения системной информации и управления используется интерфейс LuCI/ubus; для SSH-терминала и передачи файлов — SSH/SFTP.

Приложение не требует учётной записи RouterDash. В исходном коде приложения не обнаружены собственная серверная аналитика, рекламные SDK или рекламный идентификатор. Сетевые запросы управления направляются к адресу роутера, заданному пользователем. Google Play, RuStore и инфраструктура распространения Android могут обрабатывать данные в рамках собственных условий и политик.

## 3. Какие данные обрабатываются

В зависимости от включённых функций приложение может обрабатывать:

- адрес и порт роутера, имя пользователя;
- пароль LuCI для авторизации;
- SSH-адрес, порт, имя пользователя и пароль — если пользователь настраивает SSH/SFTP или фоновую автозагрузку фотографий;
- отпечаток SSH host key;
- URI выбранной пользователем папки телефона и разрешение Android на доступ к ней;
- технические сведения, получаемые с роутера: модель, имя устройства, версия системы, загрузка CPU и памяти, сетевые интерфейсы, подключённые клиенты, IP- и MAC-адреса, состояние дисков, служб, VPN и системные журналы;
- файлы и метаданные файлов, которые пользователь выбирает для передачи между телефоном и роутером.

Часть этих сведений может относиться к персональным данным или содержать сведения о других пользователях сети. Пользователь должен иметь право доступа к соответствующему роутеру и файлам.

## 4. Где хранятся данные и кому они передаются

Адрес роутера и часть пользовательских настроек сохраняются локально на устройстве. Пароль LuCI и SSH-реквизиты фоновой синхронизации хранятся с использованием Android EncryptedSharedPreferences и ключа Android Keystore. SSH host key fingerprint сохраняется в локальных настройках приложения.

При подключении данные авторизации передаются непосредственно выбранному пользователем роутеру. При использовании SSH/SFTP файлы и реквизиты передаются между телефоном и роутером. Приложение не направляет их на сервер разработчика.

**Важное ограничение текущей версии:** отпечаток SSH host key сравнивается с сохранённым значением после установления SSH-соединения. При первом подключении отпечаток сохраняется автоматически. Поэтому текущая реализация не обеспечивает полноценную проверку ключа до аутентификации и не защищает первое подключение от подмены сервера. До исправления этой реализации не используйте SSH/SFTP через недоверенные сети.

Если пользователь подключается к роутеру по обычному HTTP, пароль и управляющий трафик не защищены шифрованием на транспортном уровне. Используйте HTTPS с проверяемым сертификатом либо доверенную локальную сеть/VPN. Не отключайте проверку сертификатов.

## 5. Фоновые задачи и файлы

Фоновая автозагрузка фотографий запускается только после явного включения пользователем. Она использует выбранную папку телефона, сохранённые SSH-реквизиты и указанный каталог на роутере.

При ручной синхронизации пользователь выбирает направление передачи. При совпадении имён и конфликте файлов приложение может пропустить конфликт или заменить целевой файл в рамках выбранной операции. Исходный файл на устройстве не удаляется автоматически. Пользователь отвечает за выбор правильного каталога назначения и наличие резервной копии важных данных.

## 6. Сторонние компоненты

Приложение использует системные компоненты Android/Jetpack, OkHttp для HTTP-запросов и JSch для SSH/SFTP. Эти библиотеки используются для связи с роутером. В проверенной конфигурации зависимостей не обнаружены рекламные или аналитические SDK.

Google Play и RuStore могут обрабатывать технические данные, необходимые для распространения приложения, проверки безопасности, установки и обновления, в соответствии с собственными политиками магазинов.

## 7. Срок хранения и удаление

Настройки и сохранённые реквизиты остаются на устройстве, пока пользователь не удалит их, не очистит данные приложения или не удалит RouterDash. Разрешение Android на доступ к выбранной папке можно отозвать в настройках системы или очистив данные приложения.

Файлы на телефоне не удаляются приложением в ходе фоновой автозагрузки. При ручной передаче приложение может записывать или заменять файл в выбранном каталоге назначения. Сведения, записанные самим роутером в его системные журналы, управляются средствами OpenWrt и администратором роутера.

## 8. Защита данных

Для хранения сохранённых паролей приложение использует Android EncryptedSharedPreferences и Android Keystore. Это защищает данные, сохранённые приложением на устройстве, но не гарантирует безопасность устройства, операционной системы или сети.

Защита сетевого соединения зависит от выбранного протокола, сертификатов, настроек роутера и сети пользователя. HTTP не шифрует управляющий трафик. В текущей реализации SSH-проверка отпечатка имеет ограничение, описанное в разделе 4; до его устранения не используйте SSH через недоверенные сети.
