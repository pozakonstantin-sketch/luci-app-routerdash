## 2. Как работает приложение

RouterDash — клиент для управления маршрутизаторами на базе OpenWrt. Приложение подключается непосредственно к адресу роутера, который указывает пользователь. Для получения системной информации и управления используется интерфейс LuCI/ubus; для SSH-терминала и передачи файлов — SSH/SFTP.

У приложения нет учётной записи RouterDash, серверной аналитики, рекламных SDK, рекламного идентификатора и собственного сервиса, на который отправляется история использования. Разработчик не получает данные роутера через приложение.

## 3. Какие данные обрабатываются

В зависимости от включённых функций приложение может обрабатывать:

- адрес и порт роутера, имя пользователя;
- пароль LuCI для авторизации;
- SSH-адрес, порт, имя пользователя и пароль — только если пользователь настраивает фоновую автозагрузку фотографий;
- отпечаток SSH host key для проверки подлинности сервера;
- URI выбранной пользователем папки телефона и разрешение Android на доступ к ней;
- технические сведения, получаемые с роутера: модель, имя устройства, версия системы, загрузка CPU и памяти, сетевые интерфейсы, подключённые клиенты, IP- и MAC-адреса, состояние дисков, служб, VPN и системные журналы;
- файлы и метаданные файлов, которые пользователь явно выбирает для передачи между телефоном и SSD роутера.

Часть перечисленных сведений может относиться к персональным данным или содержать сведения о других пользователях сети. Пользователь должен иметь право доступа к соответствующему роутеру и файлам.

## 4. Где хранятся данные и кому они передаются

Адрес роутера и пользовательские настройки сохраняются на устройстве. Пароль LuCI хранится в зашифрованном хранилище Android EncryptedSharedPreferences с ключом Android Keystore, чтобы поддерживать повторную авторизацию. SSH-реквизиты для фоновой автозагрузки сохраняются в зашифрованном хранилище только после того, как пользователь самостоятельно включает эту функцию и подтверждает её настройку.

При подключении данные авторизации передаются непосредственно выбранному пользователем роутеру. При использовании SSH/SFTP реквизиты и файлы передаются непосредственно между телефоном и роутером. Приложение не пересылает эти сведения разработчику или рекламным сетям.

Если пользователь подключается по обычному HTTP, пароль и управляющий трафик не защищены шифрованием на транспортном уровне. Рекомендуется HTTPS с проверяемым сертификатом либо доверенная локальная сеть/VPN. Для SSH используется проверка сохранённого отпечатка host key.

## 5. Фоновые задачи и файлы

Фоновая автозагрузка фотографий запускается только после явного решения пользователя. Приложение не удаляет файлы автоматически. Для синхронизации используется выбранная пользователем папка на телефоне и выбранный каталог на SSD.
