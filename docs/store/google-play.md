## Полное описание

RouterDash — нативное приложение для управления маршрутизаторами на OpenWrt прямо со смартфона.

Подключайтесь к роутеру по локальной сети или через VPN и контролируйте основные параметры системы без браузера и WebView.

ВОЗМОЖНОСТИ

• Обзор роутера: модель, версия OpenWrt, время работы, загрузка процессора и оперативной памяти.  
• Сеть: интерфейсы, состояние подключения и параметры сети.  
• Устройства: клиенты сети и сведения об их подключении.  
• Диски: файловые системы, точки монтирования и использование места.  
• Службы и пакеты: просмотр состояния системных компонентов.  
• VPN: сведения о доступных VPN-интерфейсах и процессах.  
• Firewall: просмотр сетевых правил.  
• SSH-терминал: подключение к роутеру по SSH.  
• Синхронизация: двусторонняя передача файлов между телефоном и SSD роутера по SFTP.  
• Фоновая автозагрузка фотографий на SSD по расписанию.  
• Системный журнал и Android-виджет состояния роутера.  
• Защита входа по биометрии Android.

ЧТО НУЖНО ДЛЯ РАБОТЫ

• Маршрутизатор с OpenWrt и установленным LuCI.  
• Доступ к роутеру по Wi-Fi, локальной сети или VPN.  
• Для SSH и передачи файлов — доступный SSH/SFTP-сервер.  
• Для фоновой автозагрузки — выбранная папка телефона и разрешение на фоновое подключение.

КОНФИДЕНЦИАЛЬНОСТЬ И БЕЗОПАСНОСТЬ

RouterDash подключается непосредственно к указанному вами роутеру. Приложение не использует рекламу и встроенную аналитику. Сохранённые учётные данные хранятся в зашифрованном хранилище Android. Фоновая автозагрузка SSH-реквизитов включается только по вашему решению.

При подключении по HTTP пароль и управляющий трафик не шифруются. Для недоверенных сетей используйте HTTPS с доверенным сертификатом или VPN.

Приложение не заменяет резервное копирование и не выполняет автоматическое удаление файлов при синхронизации.
